# Prompts

These are the instructions given to the models, byte-identical to the files used in the corridor
run (`make demo` records each prompt's SHA-256 in the provenance of every road record it assembles
from the answers, so the files must stay as they are). Only the text below
each file's `---` line is sent to a model; the header above it is a provenance note. Paths named in
those headers (`experiments/…`, `data/informed_reading/…`, `pass_a_L.md`, `pass_c_review.md`) refer
to the author's working repository and are not part of this one. The worked example the reading
prompt refers to is in `data/worked_example/`.
